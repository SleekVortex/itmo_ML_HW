# Задание 2: Выбор и обоснование метрики качества

## 1. Специфика задачи

### Ключевые особенности:
- **Дисбаланс классов:** 73% клиентов остаются, 27% уходят (соотношение ~3:1)
- **Разная цена ошибок:** 
  - Пропустить уходящего клиента (FN) = потеря дохода
  - Ложная тревога (FP) = затраты на ненужный retention
- **Приоритет:** выявить максимум уходящих клиентов, допуская небольшое количество ложных срабатываний

---

## 2. Предложенная метрика: F1-Score

### Формула
F1 = 2 × (Precision × Recall) / (Precision + Recall)

Где:
- **Precision** = TP / (TP + FP) — какой процент предсказаний "уйдет" оказался верным
- **Recall** = TP / (TP + FN) — какой процент реально ушедших клиентов мы нашли

### Целевое значение: ≥ 0.75

---

## 3. Обоснование выбора F1-Score

**F1-метрика является оптимальной для данной задачи, так как:**

1. **Работает с несбалансированными данными**
   - Accuracy = 73% можно получить, просто всегда предсказывая "не уйдет", но это бесполезно для бизнеса
   - F1 фокусируется именно на миноритарном классе (churn), который нам важен

2. **Балансирует Precision и Recall**
   - Высокий Recall нужен, чтобы найти максимум уходящих клиентов
   - Высокий Precision нужен, чтобы не тратить бюджет на "здоровых" клиентов
   - F1 через гармоническое среднее обеспечивает баланс обеих метрик

---

## 4. Дополнительные метрики

| Метрика | Целевое значение | Зачем нужна |
|---------|------------------|-------------|
| **Recall** | ≥ 0.80 | Полнота охвата уходящих клиентов |
| **Precision** | ≥ 0.72 | Контроль расходов на retention |
| **ROC-AUC** | ≥ 0.85 | Сравнение разных моделей |

**Краткое обоснование дополнительных метрик:**
- **Recall (полнота):** показывает, сколько реально ушедших мы выявили. Пропуск уходящего клиента = прямая потеря CLV, поэтому Recall критически важен.
- **Precision (точность):** показывает, можно ли доверять предсказаниям модели. Низкий Precision = много ложных тревог = перерасход бюджета и раздражение клиентов.
- **ROC-AUC:** помогает сравнивать модели и настраивать порог классификации в зависимости от бизнес-приоритетов.
