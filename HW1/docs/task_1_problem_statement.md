# Задание 1: Постановка задачи прогнозирования оттока клиентов

## 1. Бизнес-постановка задачи

### Описание проблемы
Телекоммуникационная компания теряет клиентов, что снижает прибыль. Привлечение нового клиента в 5-7 раз дороже удержания существующего. Увеличение удержания может повысить прибыль.

### Бизнес-цель
Разработать систему предсказания оттока клиентов для:
- Проактивной идентификации клиентов с риском ухода
- Оптимизации затрат на программы удержания
- Персонализации предложений (скидки, специальные тарифы)
- Снижение оттока клиентов

### Ожидаемые бизнес-результаты
- Увеличение CLV (customer lifetime value)
- Точность выявления уходящих клиентов ≥ 80%

---

## 2. Постановка ML-задачи

### Тип задачи
**Бинарная классификация** (Binary Classification)

### Формализация
Для каждого клиента предсказать вероятность оттока:
- **y ∈ {0, 1}** — целевая переменная (0 = остался, 1 = ушёл)
- **X** — вектор признаков клиента

### Группы признаков
1. **Демографические:** пол, возраст, семейное положение, иждивенцы
2. **Услуги:** интернет, телефония, доп. сервисы (безопасность, ТВ, поддержка)
3. **Контракт:** тип контракта, способ оплаты, срок работы с компанией (tenure)
4. **Финансовые:** ежемесячные платежи, общая сумма платежей

### Особенности задачи
- **Дисбаланс классов:** 73% остаются, 27% уходят (~3:1)
- **Интерпретируемость:** важно понимать факторы оттока для стратегий удержания

## 3. Источник данных

### Датасет: Telco Customer Churn
- **Источник:** IBM Sample Data Sets / Kaggle
- **Размер:** 7,043 записей × 21 признак
- **URL:** https://www.kaggle.com/datasets/blastchar/telco-customer-churn

### Основные переменные

| Тип | Примеры признаков |
|-----|-------------------|
| **Демография** | gender, SeniorCitizen, Partner, Dependents |
| **Услуги** | InternetService, PhoneService, OnlineSecurity, TechSupport, StreamingTV |
| **Контракт** | Contract, tenure, PaymentMethod, PaperlessBilling |
| **Финансы** | MonthlyCharges, TotalCharges |
| **Целевая переменная** | **Churn (Yes/No)** |

---

## 4. Ожидаемый результат

### ML-модель
Обученная модель бинарной классификации с характеристиками:
- **F1-score** ≥ 0.75
- **Recall** ≥ 0.80 (выявить 80%+ уходящих клиентов)
- **Precision** ≥ 0.72 (контроль ложных срабатываний)
